# Tapiceria de confianza
# Tapicería de Confianza  Tapicería de Confianza es un sitio web desarrollado para modernizar la presencia digital de un negocio dedicado a la restauración, reparación y fabricación de muebles tapizados.  El proyecto fue diseñado con un enfoque en la experiencia del usuario, permitiendo a los clientes conocer los servicios ofrecidos, visualizar trabajos realizados y contactar fácilmente con la empresa para solicitar presupuestos personalizados.  La plataforma presenta un diseño moderno, adaptable a dispositivos móviles y optimizado para ofrecer una navegación clara e intuitiva. Además, incorpora secciones informativas, galería de proyectos, formularios de contacto y elementos visuales orientados a generar confianza y credibilidad en potenciales clientes.  ## Objetivos del proyecto  * Modernizar la imagen digital de un negocio local. * Facilitar la comunicación entre clientes y empresa. * Exhibir trabajos realizados mediante una galería visual. * Mejorar la presencia online y la captación de nuevos clientes. * Aplicar buenas prácticas de desarrollo web y diseño responsive.  ## Tecnologías utilizadas  * HTML5 * CSS3 * JavaScript * Diseño Responsive * Git y GitHub para control de versiones  ## Características principales  * Diseño adaptable para computadores, tablets y móviles. * Sección de servicios detallada. * Galería de trabajos realizados. * Formulario de contacto. * Navegación intuitiva y moderna. * Optimización visual enfocada en pequeños negocios y emprendimientos.
